Install Java 21
Required — Backend ▾

The backend is built with Java 21. Download the free Temurin distribution from Adoptium.

Install via Homebrew (easiest):

# Install Homebrew if you don't have it
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Install Java 21
brew install --cask temurin@21
💡 Or download the .pkg installer directly from adoptium.net

Download the Windows installer (.msi):

🔗 Go to adoptium.net → Download JDK 21 — Windows x64 .msi → Run the installer → ✅ check "Set JAVA_HOME" during setup. 
# Ubuntu / Debian
sudo apt update
sudo apt install -y wget apt-transport-https
wget -O - https://packages.adoptium.net/artifactory/api/gpg/key/public | sudo tee /etc/apt/keyrings/adoptium.asc
echo "deb [signed-by=/etc/apt/keyrings/adoptium.asc] https://packages.adoptium.net/artifactory/deb $(awk -F= '/^VERSION_CODENAME/{print$2}' /etc/os-release) main" | sudo tee /etc/apt/sources.list.d/adoptium.list
sudo apt update && sudo apt install -y temurin-21-jdk

Verify installation:

java -version
# Expected output: openjdk version "21.x.x" ...

Install Node.js 20+
Required — Frontend ▾

The Angular frontend requires Node.js 20 or higher.

brew install node@20
brew link node@20
🔗 Download the LTS installer (.msi) from nodejs.org and run it. 
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

Then install the Angular CLI:

npm install -g @angular/cli

Verify:

node -v   # v20.x.x
ng version # Angular CLI: 18.x.x

Install PostgreSQL 16
Required — Backend ▾

The backend stores all data in PostgreSQL. Install it and make sure the service is running.

brew install postgresql@16
brew services start postgresql@16
# Add to PATH (add this line to ~/.zshrc or ~/.bashrc)
echo 'export PATH="/opt/homebrew/opt/postgresql@16/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc
🔗 Download the installer from postgresql.org/download/windows. During setup: keep default port 5432, set a password you'll remember, and install pgAdmin (check the box).
⚠️ Remember the password you set for the postgres superuser — you'll need it in the next step. 
sudo apt update
sudo apt install -y postgresql-16
sudo systemctl start postgresql
sudo systemctl enable postgresql

Verify PostgreSQL is running:

psql --version
# psql (PostgreSQL) 16.x
4
Create the Database
Required — Backend ▾

Create the helpdesk database and a dedicated user. The app will create all tables automatically on first run via Flyway.

# Open the PostgreSQL shell
psql -U postgres

# Run these commands inside psql:
CREATE DATABASE helpdesk;
CREATE USER helpdesk WITH PASSWORD 'helpdesk';
GRANT ALL PRIVILEGES ON DATABASE helpdesk TO helpdesk;
\q
💡 On macOS with Homebrew, the default superuser matches your Mac username. Try psql -U $(whoami) if psql -U postgres fails.

Open pgAdmin 4 (installed with PostgreSQL), connect to your server, then open the Query Tool and run:

CREATE DATABASE helpdesk;
CREATE USER helpdesk WITH PASSWORD 'helpdesk';
GRANT ALL PRIVILEGES ON DATABASE helpdesk TO helpdesk;

Install MailHog (Email Testing)
Optional ▾

MailHog catches outgoing emails so you can view them in a browser without a real SMTP server. The app runs fine without it — email notifications just won't appear.

brew install mailhog
mailhog &
# MailHog web UI → http://localhost:8025
🔗 Download MailHog_windows_amd64.exe from github.com/mailhog/MailHog/releases and double-click to run it. 
wget https://github.com/mailhog/MailHog/releases/download/v1.0.1/MailHog_linux_amd64
chmod +x MailHog_linux_amd64
./MailHog_linux_amd64 &
⚠️ Skipping MailHog? That's fine. The backend will log a connection warning but will still start and work normally.

Run the Backend
Required ▾

Open a terminal in the project root and run the following. Keep this terminal open while using the app.

# Navigate to the backend folder
cd helpdesk-pro/backend

# Set environment variables
export DB_USER=helpdesk
export DB_PASS=helpdesk
export JWT_SECRET=dev-secret-key-change-in-production-min-32-chars
export MAIL_HOST=localhost
export MAIL_PORT=1025
export FRONTEND_URL=http://localhost:4200

# Start the backend
./mvnw spring-boot:run
:: Navigate to the backend folder
cd helpdesk-pro\backend

:: Set environment variables
set DB_USER=helpdesk
set DB_PASS=helpdesk
set JWT_SECRET=dev-secret-key-change-in-production-min-32-chars
set MAIL_HOST=localhost
set MAIL_PORT=1025
set FRONTEND_URL=http://localhost:4200

:: Start the backend
mvnw.cmd spring-boot:run
✅ Backend is ready when you see: Started HelpdeskApplication in X seconds
ℹ️ First startup downloads Maven dependencies (~2 minutes). Subsequent starts are much faster.

Verify the backend is running:

curl http://localhost:8080/actuator/health
# Expected: {"status":"UP"}
📖 Full API documentation: http://localhost:8080/swagger-ui.html
7
Run the Frontend
Required ▾

Open a second terminal (keep the backend terminal running) and run the following.

# Navigate to the frontend folder
cd helpdesk-pro/frontend

# Install dependencies (first time only, ~1 minute)
npm install

# Start the frontend dev server
ng serve
✅ Frontend is ready when you see: ✔ Compiled successfully and Application bundle generation complete
⚠️ Make sure the backend (Step 6) is running first, otherwise API calls will fail in the browser.

Troubleshooting
If something fails ▾
ErrorFix
./mvnw: Permission denied Run chmod +x mvnw inside the backend folder
Connection refused port 5432 PostgreSQL not running — run brew services start postgresql@16 (Mac) or sudo systemctl start postgresql (Linux)
password authentication failed DB credentials don't match — re-run Step 4 and make sure DB_USER/DB_PASS env vars are set
Port 8080 already in use Mac/Linux: lsof -ti:8080 | xargs kill   Windows: netstat -ano | findstr :8080 then taskkill /PID <pid> /F
ng: command not found Run npm install -g @angular/cli then try again
Flyway migration error on startup Drop and recreate the DB: DROP DATABASE helpdesk; CREATE DATABASE helpdesk; then grant privileges again
Login fails (401) in the browser Make sure backend started successfully and is still running in the other terminal
