Reusable skeleton same every time

Event-driven trigger AFTER_COMMIT listener Dedicated single/small-pool executor Idempotency guard Scope guard try/catch wrapper Resolved-by-agent flag + badge

Every future single-purpose agent (KB-search-and-reply, duplicate-merge bot, SLA-escalation bot, etc.) can be built as a new <Name>AgentService + matching event/listener pair, dropped into this same harness — without re-deriving the plumbing.
